# StockHub

تطبيق Android محلي لإدارة مخزون محل الإلكترونيات (قطع غيار + بيع).
يعمل بدون إنترنت ويحفظ البيانات في Room على الجهاز.

## المميزات
- تبويبات: الرئيسية · قطع الغيار · البيع
- تصنيفات مربعة بأيقونات
- إضافة / تعديل / حذف + زيادة ونقص الكمية
- حد طلب وتنبيه الأصناف الناقصة
- ريموتات HD / SD / تلفزيون مع الماركات
- **إعدادات**: مظهر (نظام / داكن / فاتح) + لغة (عربي / إنجليزي)
- أيقونة مخصصة واسم التطبيق StockHub

## البناء
افتح مجلد `Fatateer` في Android Studio → Sync Gradle → Run
أو Build → Build APK(s)
